# RecordActionDeployment

[Back to catalog](README.md)

## `record-action-deployment/not-empty`

Reports a deployment with all action sources turned off, because it renders empty.

**Properties:**

- `severity`: [rule level](README.md#common-configuration)

**Example:**

```json
{
  "rules": {
    "record-action-deployment/not-empty": "warn"
  }
}
```
