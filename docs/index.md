# Gardener

Gardener is a plugin for the Salesforce CLI that runs static analysis on the metadata of Salesforce DX projects.

## Use Gardener in your project

- [Getting started](/getting-started/): install the plugin and run it for the first time.
- [Core concepts](/concepts/): scope, projects and how the analysis works.
- [Configure](/configuration/): choose and tune the rules.
- [Command line reference](/cli/): commands and options.
- [Rules reference](/rules/): every rule, grouped by metadata type.
- [Presets](/presets/): the rules enabled by `recommended`.
